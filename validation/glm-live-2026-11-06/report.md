# GLM 标准 API 双 Agent 小规模真实试验

2026-11-06。已真实调用智谱普通 API `glm-5.3-flash`，完成 Thinking、原生工具结果回传、两道开发题的双 Agent 修复和独立外部复验。两批共 **8 次运行、2 道不同题**；两批不合并为一个修正后的成功率。

- **完整流程**：在功能通过之外，Agent 正常结束、观测到初始测试及最后修改后的测试、没有终止错误。允许已记录的中间失败及恢复，不能解释为“全程零异常”。
- **第二次独立外验**：另建执行器和副本，使用原冻结测试及合法实现文件重新运行；每份最终代码都是 3/3 测试通过。原始记录逐文件哈希核对未改变。

题目为既有 ProcessBench `dev_interval_end`（单文件区间右边界）与 `dev_sku_contract`（跨文件参数和规范化契约）。均为已参与资产自检和离线开发的**合成开发题**，每题每 Agent 每批 1 次。不是留出集、真实开源故障或 SWE-bench；每题仅三个测试，不能证明仓库级修复泛化或稳定排名。全部原始失败保留。

验收测试允许读取、禁止修改，外部验证器使用冻结副本；没有另行隐藏测试。这验证对明确契约的修复，不应宣传为对未知行为的全面验证。

## 发现的问题及修正边界

1. **初始 ApeCode 单文件运行**：第四个响应缺少 `reasoning_content`，服务端明确报告 `reasoning_tokens=0`；代码已改正确，但 Harness 在执行最终测试前拒绝响应。功能通过、流程失败。修正后只对“无文本且思考 Token 为整数 0”的 GLM 响应豁免该字段必需检查；不补造空思考、不删改已有文本。
2. **初始 ApeCode 跨文件运行**：同样缺少思考文本，但服务端报告 **32 个思考 Token**。这是另一类返回不一致，仍保守拒绝；不能把它说成已由零 Token 修正解决。代码经外验通过，Agent 未完成最终重测，流程失败。
3. **复测 CodeTrail 跨文件运行**：遇到两次缺少文本但报告 25 个思考 Token 的响应，均拒绝执行。原有循环记录反馈后在后续请求得到完整响应并执行测试，最终通过。故复测仍有 **2 次协议拒绝**；没有声称根除服务端字段异常。ApeCode 本批未遇到正数缺失场景，其初始终止策略保持不变。
4. 原样回传已返回的思考文本：按原生调用 ID 对齐后续实际请求，本次所有可观察回传均未发现文本改写；精确次数和每轮缺失类型见 [analysis.json](analysis.json)。这不证明服务端未返回的思考内容可恢复。
5. 首次环境代理请求发生 `URLError`，无可靠 HTTP 响应。另开直连预检成功后，两个批次显式冻结 `network_route=direct`。保留失败记录，未将其归因于模型慢、余额或服务器故障。
6. 最终回答仍需与轨迹核对：复测 ApeCode 跨文件回答将策略拒绝描述为测试输出提示，轨迹实际显示是 `update_plan` 调用被拒绝；测试退出码和修复文件陈述则与外验一致。本轮没有可靠的完整语义忠实性金标，不发布忠实性满分。

这次修正的受控证据是同题、同计划、同模型参数、同 worker 和上游源文件哈希，修正前后另行冻结；**不意味着随机模型行为只受一个变量影响**，也不能把 ApeCode 流程 0/2→2/2 全部归功于零 Token 兼容修正。服务端正数思考用量却不返回文本的问题仍需进一步确认协议保证，未通过猜测内容或放宽工具执行来绕过。

## 固定配置、版本与费用

- 普通 API：`https://open.bigmodel.cn/api/paas/v4/chat/completions`；请求和全部成功响应均为 `glm-5.3-flash`。实际连接成功 HTTP 200；另有两次真实请求验证原生工具调用、真实 echo 结果及 Thinking 回传。没有使用 Coding Plan 或客户端身份伪装。
- Thinking enabled、`clear_thinking=false`、`reasoning_effort=max`；temperature=1、top_p=0.95、max_tokens=4096；非流式，180 秒请求超时，单次传输，无自动 HTTP 重试；并发 1，工具最多 20 次、请求最多 30 次、worker 最多 645 秒。
- 两 Agent 使用 Python 3.13.11。ApeCode 原始循环及工具版本由六个上游文件 SHA256 锁定；CodeTrail、适配器、配置和任务归档随批次冻结。模型别名仍可能被平台更新，未宣称固定权重。
- 初始冻结 SHA256：`490b45c0fbaad44873c221c9c0d2da49be284b4f56ec3e3c0c8bfd4e99d626b2`。
- 修正后冻结 SHA256：`502be75bf34603973d2c40463294994d019abe6d20433489abb0cd286d84ce02`。
- 普通 API 单价按查询日记录：输入 0.8 元/百万 Token、输出 2.8 元/百万、缓存输入 0.23 元/百万。全部输入按未命中缓存估算，因此为**标价上界估算，不是账户实扣**。初始批次 0.0747792 元，复测 0.0804788 元；含预检共 **0.1564940 元**。另对代理失败且用量未知的请求保留 **0.0074832 元**预算预留，未知用量没有按零处理。共享预算上限 1 元；发送前按本地保守字节估计预留，不宣称获得平台精确预 Token 计量。

定价与协议依据：[官方价格](https://docs.bigmodel.cn/cn/guide/start/pricing)、[GLM 模型说明](https://docs.bigmodel.cn/cn/guide/models/vlm/glm-5.3-flash)、[Thinking 文档](https://docs.bigmodel.cn/cn/guide/capabilities/thinking-mode)。零 Token 例外依据是保存的真实响应，而非声称官方保证所有轮次都具有相同字段。
