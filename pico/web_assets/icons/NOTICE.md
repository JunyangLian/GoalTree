# 图标来源

GoalTree 的 `goaltree.svg` 是本项目原创的“分支树与目标节点”标识，按项目MIT许可提供。`goaltree.png`和多尺寸`goaltree.ico`从同一SVG导出，用于兼容浏览器标签与网页快捷方式，图案一致。

`superpowers.svg`为GoalTree设计的Superpowers集成标识：“能力火花＋工具”，紫色底、浅色扳手和金色星芒，按项目MIT许可提供。它不是上游官方Logo。`superpowers.png`是同一SVG的兼容导出，替代此前的作者头像；插件与相关技能统一使用这一设计。

第三方图标用于标识对应项目/服务，不表示合作或背书，不改变原商标权利。图像本地保存，浏览目录不会为加载图标向第三方发起请求。
