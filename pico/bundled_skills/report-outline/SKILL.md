# 报告提纲

适用于报告、会议准备、阶段总结与汇报文档。
1. 优先复用用户已给的主题、听众、时长和资料；缺少决定内容的大方向时只问关键问题。
2. 先给适合时长的提纲，区分事实、判断、假设和待补信息，避免直接生成无依据长文。
3. 每一节写清核心问题、支持证据、建议图表和预期结论。会议任务区分会前材料、会议议程、行动项。
4. 用户要求调整交付物时，同步GoalTree对应Task的描述和验收，而非只改标题。
5. 只引用实际读取的材料。若要求保存文件，使用既有文件工具和审批，给出实际文件位置。
文档结构正确不等于内容已核实；未确认的来源、数字和结论明确标注。

以上为按需工作流建议，不授予权限、不运行脚本；当前用户要求、GoalTree策略和审批优先。
