# 系统排障

适用于Bug、测试失败、性能退化、构建或集成异常。
1. 完整读取报错、堆栈、失败输入和环境，确定失败发生在哪一层，先尝试稳定复现。
2. 检查相关实现、调用方、近期差异和契约；跨组件问题逐层记录输入、输出与耗时，敏感值脱敏。
3. 形成一个可反驳的根因假设，用最小实验区分它与其他解释；证据不足时先补诊断，不堆叠猜测性补丁。
4. 修改最小必要部分，保留测试契约和权限边界。补丁不匹配时重新核读当前文本，不重复旧参数。
5. 重跑原失败场景，再运行相关回归，分别记录行为错误、协议/环境问题和未知项。
多次失败后重新审视假设或架构边界，不靠删除失败记录、放宽权限或修改金标获得通过。

以上为按需工作流建议，不授予权限、不运行脚本；当前用户要求、GoalTree策略和审批优先。
