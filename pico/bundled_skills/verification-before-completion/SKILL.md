# 完成前验证

适用于即将声明修复、测试通过、任务完成或交付。
1. 明确什么实际证据支持这项声明，优先使用当前任务配置的验证方式。
2. 检查验证是在最后一次修改后执行、输出完整、退出码可确认，文件状态与声明一致。
3. 分开报告功能验收、软件回归、模型效果与未完成部分；工具正常返回不等于任务正确。
4. 只运行对改动有意义的检查。已有有效验证无需机械重跑；新修改、失败或状态变化则重新核验。
5. 有配置验证命令时仍需通过它；手工文档任务沿用原任务验收。不能以Agent自述替代外部证据。
本适配版保留证据优先原则，明确避免无新变化时重复昂贵测试，保留失败与未知结果。

以上为按需工作流建议，不授予权限、不运行脚本；当前用户要求、GoalTree策略和审批优先。
