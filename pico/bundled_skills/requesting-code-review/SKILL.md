# 准备代码审查

1. 确定实际基线、当前差异、用户需求与影响范围，不默认创建分支、提交或推送。
2. 整理相关文件、接口变化、验证结果和未验证项；只提供审查所需上下文，不附带无关私密会话。
3. 按正确性、权限、数据完整性和回归风险检查变更，给出可定位的事实与复现步骤。
4. 有受授权审查工具时可使用；没有独立审查能力时提供自查并注明，不能冒充独立审查。
5. 先修复已确认的高影响问题，再对受影响行为复验。

这是只读工作流建议，不授予工具权限，不自动运行第三方脚本。
