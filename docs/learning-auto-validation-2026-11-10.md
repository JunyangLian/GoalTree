# 后台自动学习验收 · 2026-11-10

此版本替换第一版的人工学习治理流程。主界面不再包含“经验与技能”、刷新记录、保存反馈、候选试用或学习确认。用户通过正常对话推进目标，Agent 与宿主根据证据自动处理学习。原工具审批、路径限制、任务验收和隔离配置保持不变。

## 自动闭环

- 当前用户消息进入有来源的上下文，模型可提炼偏好和纠正；明确记忆指示有原话记录兜底，不要求使用固定口令。明确不保存与敏感内容跳过，不因学习失败阻塞普通对话。
- 直接用户反馈、确定性失败现象可自动形成有效记忆；任意运行总结不能自行批准。普通聊天不强制反思。
- 自动选择一条相关候选，在已授权的任务中作为建议试用；没有额外学习审批，也不会为试用创建无关工作。
- 不同 Task 的有效通过收据触发 Skill 自动晋升；同题换 Run、回复完成和模型自述不算通过。
- 相同内容去重，纠正/合并保留前序版本并检查并发冲突；来源变化或到期停止召回。
- 执行经验/Skill与两道不同 Task 的实际配置验证失败关联时，自动停用并在有有效前序版本时恢复。API 中断、取消、未知结果不算技能退化。明确用户偏好不因无关代码测试失败而回退。
- 所有自动事件留在私有数据库和 Run 轨迹，不新增用户需要维护的页面。

细节、边界和复跑命令见[学习模块](learning.md)。宿主 CLI/API 为诊断与紧急恢复保留，不是默认交互流程。

## 离线真实工具 Demo

`scripts/run_learning_demo.py` 使用固定决策、真实文件修改及unittest。流程为：

1. 修复递增函数，通过配置测试，自动生成候选 Skill。
2. 对新字符串归一化 Task 自动选择并试用候选，真实验证通过后自动晋升，不传入人工试用选择，也不调用人工启用。
3. 后续任务召回记忆、加载已启用 Skill；仅查看，没有验收，不算成功。
4. 反馈形成的记忆自动生效，后续纠正自动替代，旧版本保留。

九项闭环检查全部通过，审计链22个事件一致；独立进程复验两项unittest均通过，并保存文件SHA256。Demo的反馈来源和模型决策是夹具，不能当作外部模型能力，也不并入任何Benchmark。自动回退使用带明确结果的单元/集成夹具验证，不虚构真实模型退化实验。
