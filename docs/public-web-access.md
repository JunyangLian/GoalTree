# 公开网页检索

`start-goaltree.cmd`和`scripts/run_goaltree_glm.py`默认启用`web_search`、`web_read`，当前普通搜索默认走[Exa Search MCP](search-mcp.md)。无需添加搜索服务凭据。页面左下方显示“可联网”，进度栏显示“搜索网页”“读取网页”及对应查询/地址。搜索摘要用于发现来源，事实结论尽可能读取官方正文并引用来源链接。文件夹工作区切换保持宿主选定的联网配置，各会话证据仍分开保存。

例如：**联网搜索鱼类RNA-seq质量控制的官方资料，阅读两个主要来源，然后帮我整理报告提纲，并附链接。** 简单的目标规划不必自动搜索；用户提供的私密文档不应直接作为搜索词发出。

| 工具 | 参数 | 返回 |
|---|---|---|
| `web_search` | `query`，1–400字符；`limit`，1–5，默认3；`source`，默认`auto`；`refresh`，0/1 | 多源标题、URL、摘要/元数据，逐源状态、请求哈希与获取时间 |
| `web_read` | `url`或`page_id`二选一；`start`，默认1；`limit`，默认10、最多20；`refresh`，0/1；`pdf_page`，0或1–40（仅PDF、start=1） | 清洗后的编号行、PDF物理页码、快照ID、来源/时间/版本哈希、继续读取位置与片段引用 |
| `web_find` | `page_id`、字面`pattern`、`limit`默认3（最多3） | 页内匹配位置和片段；无网络请求 |

### 搜索来源

| source | 实际渠道 | 用途 |
|---|---|---|
| `auto`（默认） | 配置MCP时调用Exa；public后端先Bing，必要时补百度与微信索引 | 快速查询 |
| `mcp` | 已配置的Exa hosted Search MCP，无静默回退 | 默认普通搜索的显式写法 |
| `compare` | Bing、百度、微信索引三路并行 | 明确需要覆盖或交叉核对 |
| `bing` / `baidu` / `wechat` | 明确指定其中一个 | 需要核对某个搜索引擎时使用 |
| `research` | Crossref和PubMed并行 | 学术文献，生物医学主题优先考虑PubMed |
| `crossref` | Crossref公开REST API | DOI、标题、期刊和发表日期；[官方说明](https://www.crossref.org/documentation/retrieve-metadata/rest-api/) |
| `pubmed` | NCBI ESearch + ESummary | PMID、标题、期刊和发表日期；[官方说明](https://www.ncbi.nlm.nih.gov/home/develop/api/) |
| `all` | 上述五个实际来源 | 明确需要跨渠道查证时使用，不作为每轮默认 |

用户可说“用百度搜索……”或“用微信文章搜索……”或“用PubMed与Crossref检索鱼类RNA-seq论文”。选择由LLM通过原生工具参数完成，不另加模式切换面板或关键词路由器。Crossref和PubMed是独立专业数据源，不是给Bing套站点过滤；返回的是书目信息，不能视为阅读了全文，更不能据此直接断言论文支持某个结论。

Bing使用公开RSS，百度读取公开搜索页中可识别的结果区块，微信渠道读取[搜狗微信公开文章索引](https://weixin.sogou.com/)中已识别的标题、摘要、公众号与搜索跳转链接；不是微信全量/登录态搜索。没有结果与验证码、JS跳转、布局变化分别记录，不执行JS、不绕过验证、不沿HTTPS降级跳转。这些网页入口没有稳定API保障。百度本机实时请求当前触发验证，不能声称已成功返回结果；百度解析器正常结果路径由固定HTML样例验证。当前未将连通性探测失败的DuckDuckGo、Wikipedia等接入为可用渠道。搜索覆盖、排名和时效由提供方决定。Bing RSS与用户浏览器的Bing结果可能不同；一次空集、噪声结果或预算用尽均不能证明网页不存在、未被索引、仅内网可见或尚未发布。只能说明本轮在实际尝试的渠道中未找到充分证据；查询会议时须核对年份和届次，旧会议仅作线索。

每次多源调用最多三路并发（`all`含五源，共用截止时间），所有子请求共享8秒阶段预算；`auto`不强制等待第二个搜索源。PubMed在本进程中按至少0.35秒间隔发送请求，遵循无Key下每秒最多3次的[官方限制](https://support.nlm.nih.gov/kbArticle/?pn=KA-05317)；其他程序使用相同出口IP时仍需协调总量。PubMed数据使用同时遵循[NLM免责声明与版权声明](https://www.ncbi.nlm.nih.gov/About/disclaimer.html)。

对包含多个词组的普通查询，使用词组/中文二元字组覆盖及未匹配词组作轻量噪声提示（包括地点/年份匹配但主题缺失的情况）；这不是语义相关性或正确性评分，不过滤或删除原始结果。`auto`遇到低匹配结果时只并行补一次百度与微信索引，仍共用原8秒阶段预算（Bing预留最多4秒，余量由两个备用来源共享）。`auto`中明显低匹配的Bing结果排在备用来源之后，再按RRF排序；显式多源`compare`仍保持原RRF融合；单词查询不强制扩搜，显式`bing`仍不换源。检索路径变更使用新缓存版本，旧证据保留。

结果按规范化的完整URL去重（去除fragment，不把不同DOI/PMID或查询参数合并），通过RRF融合源内排名；该值只用于排序，不是可信度或能力得分。同一URL保留全部命中的来源。输出预算不足时会减少展示条目并标注截断；每源`count`是截断融合之前解析得到的条目数。最多返回`limit`条融合结果，不是每个来源各`limit`条。

部分渠道失败返回`partial`和可用结果，轨迹标为`partial_success`，前端明确显示各来源状态；所有指定渠道失败则工具报错。明确指定某个来源不会静默换到Bing。没有结果、协议/布局变化、HTTP拒绝和超时分别保留实际状态，不生成虚构结果。

## 网络边界

- 仅GET公开HTTP(S)的80/443端口，不发送Cookies、认证头、API Key或用户自定义请求头，不沿用宿主代理设置。固定诚实的`GoalTree/0.1`标识。
- DNS解析结果必须全部为可接受的公开地址；拒绝混合公网/私网结果、回环、链路本地、保留和组播地址，以及IPv4映射、6to4、Teredo与常见NAT64转换地址。实际连接固定到已检查的数字IP，HTTPS仍校验原始主机名证书。
- 最多3次重定向，每跳重新检查，拒绝HTTPS降级；HTML/文本至多512KiB，PDF至多5MiB。单次Socket等待上限5秒；网页工具的网络阶段上限8秒，本轮累计网络阶段预算20秒。DNS与Socket分阶段行为使其不是硬实时总时限，模型生成时间另计。支持取消检查，已阻塞的网络操作需等待其超时。
- 只读HTML、纯文本、PDF和搜索RSS；不执行JS、不任意下载二进制、不访问需登录页面。PDF只接受application/pdf及有效文件签名，保留原重定向和DNS校验；在独立有限资源解析进程中提取文字，不执行PDF动作/附件。清洗正文保存在会话快照中，按编号行分段进入模型；整体JSON控制在工具输出预算内，范围和引用指针按实际返回的行更新。
- 工具把页面内容标记为不可信数据。网页要求执行命令、泄漏文件、改变目标或绕过审批不构成授权。现有已知凭据脱敏检测命中时拒绝发出查询/URL；这不是通用敏感信息识别或模型不受Prompt Injection影响的保证。
- 这是宿主上的受控公开网络读取通道，**并非给Shell/AppContainer开放互联网**。代码执行、写文件、用户验收继续走原策略。该功能默认关闭于普通Workbench构造和历史评测入口，不改写旧Benchmark的网络条件。

## 来源、审计与关闭

完整工具输出保存在对应会话的`.pico/evidence.sqlite3`，运行事件保存在`.pico/web/tasks`等原有审计目录。轨迹预览可能截短，通过证据ID可取回原工具输出。哈希是该次收到的响应字节哈希，正文仅保存提取摘录；不等同于完整原网页归档，也不保证未来再次获取相同页面。

```powershell
# GLM入口默认开启；以下显式关闭：
python -X utf8 scripts/run_goaltree_glm.py --workspace <目录> --no-web-access
# 通用入口默认关闭，以下显式开启：
python -X utf8 -m goaltree.web --cwd <目录> --harness-profile workbench --web-access
```

功能验证见[最初记录](releases/goaltree-2026-11-10.md)与[多源接入记录](releases/goaltree-2026-11-10.md)。真实模型验证只演示搜索、阅读和来源呈现，不作为联网研究质量或代码修复成功率评测。

## 快照、引用和轻量预算（2026-11-09）

用户提供URL时直接读取，不先重新搜索。LLM根据证据缺口决定查找片段、继续阅读、改写查询或停止；没有新的关键词路由器或额外摘要模型调用。默认路径是一轮搜索和一到两张有用页面；资料齐备时结束，不把每个问题自动扩展为深度研究。

查询和URL缓存默认900秒，按工作区及会话隔离，读取最近32个同类缓存候选。网页快照保存到原有本地`evidence.sqlite3`：网页ID对应不可变的清洗正文和元数据；历史证据保留，不因缓存过期删除。`web_read(page_id=...,start=...)`、`web_find`只读授权快照，不访问网络。分页行号是清洗/折行后的快照位置，不是原站HTML行号；提供响应字节哈希与清洗文本哈希以区分二者。片段指针帮助核对出处，不是自动语义判真器。

`refresh=1`显式重新请求并产生新版本，仅可随URL或搜索查询使用。过期的URL缓存不作为当前结果命中；明确按ID查看历史快照会显示`stale`与年龄。强制刷新保证发起新请求，不保证搜索提供方的索引或网站内容本身最新。不得仅因摘要或当前分页没有提及某事就断定原文不存在。

每轮预算：最多2次新的联网搜索、3次新资源获取（一次PDF获取计一次，不是3个物理页）、8次网络尝试（含重定向/失败）、20秒累计网络阶段耗时。输出配额：当前GLM入口120,000字符/轮、12,000字符/次、每次最多120行；普通Workbench默认10,000字符/轮、3,800字符/次、每次最多20行（含元数据，不能当作Token统计；以/api/config及工具说明为准）。失败/刷新消耗相同预算，缓存命中/页内读取不消耗网络次数；这些本地操作仍消耗普通工具步数和网页输出预算。GoalTree分派的子Task共享父轮预算，不能靠新建子Task重置。预算停止有独立审计错误码，要求使用现有证据并说明缺口。网络阶段预算包含该阶段解析开销，不包含阶段之间的模型推理，不能承诺整轮回答在20秒内完成。

[本轮实现与验收](releases/goaltree-2026-11-10.md)保留真实运行与缓存证据；它不是大规模检索质量Benchmark。

网页快照保留最多100个可解析HTTP(S)链接/内嵌页面地址，单个地址最多500字符，支持从官网索引追踪相对文章链接。链接本身不触发请求，打开时继续走原网络安全校验。以文字链接表示，内嵌页面明确标为尚未读取，不执行网页脚本或自动加载iframe；纯图片中的日程、海报仍不属于已读取正文；公开PDF现可通过返回的document_urls调用web_read继续读取，未读取前仍明确标记，方法见[PDF读取](pdf-reading.md)。

## Bing + 百度 + 微信（2026-11-10）

当前已移除360适配器、默认源及恢复提示；`source=360`在联网前被拒绝。历史运行与验收报告保留原样，不把旧结果改写成新渠道结果。

微信返回的可能是`weixin.sogou.com/link?...`临时搜索跳转地址，明确标记`link_kind`，可包含公开站点生成的临时token；它不是本地模型Key，不能据此推测出`mp.weixin.qq.com`文章URL或声称已读全文。跳转/文章读取时仍经过原网络限制；验证、过期或JS需求如实报错。

完整搜索报告（包含每次HTTP元数据、URL、哈希及所有合并结果）写入现有会话EvidenceStore；工具给模型的预览保留逐源状态、可用结果和`audit_evidence_id`，移除冗长的内部请求清单，避免验证码跳转URL把微信结果挤出上下文。失败和partial报告同样归档，partial不缓存；所有源失败时也保留报告指针。网络次数、字节上限、总体预算及执行权限不变。

验收记录：[发布检查](releases/goaltree-2026-11-10.md)。本轮实际调用公开搜索工具，不含新的GLM成功率实验。
