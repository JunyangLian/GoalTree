## 实现与检查

- 输入框旁增加“记忆互联 · 关闭／开启”，默认关闭；保存采用会话绑定和revision，切换／刷新不串设置。

- 关闭后停止后续共享检索，旧产出不自动删除；外部修改设置或撤销已呈现条目时，下一调度前停止。
