## 实际验收

使用 Tabbit 官方已安装 CLI，在新建的本地测试文件夹通过网页操作完成：

- 从左栏打开插件面板，插件/技能/MCP 分别显示 3/7/5 项。
- 技能预览、文本搜索、返回列表和重新打开。
- 关闭开发排障插件包，重新加载网页确认配置仍存在，再恢复启用。
- 本地文档 MCP 的真实子进程协议检测通过；检测不查询文档，实际工具仍沿用原审批。
- 在面板启用 Context7 并检测，协议与工具发现通过，再恢复默认关闭。
- GitHub 显示缺少本地凭据；Playwright 显示“配置模板 · 未接通”，没有启用开关。
- 480px 窄屏下对话框宽 443px、scrollWidth 443px，卡片转为单列；恢复桌面尺寸。

未修改用户已有目标。工作区切换、请求绑定、CAS 冲突、CSRF 和外来 Origin 拦截另由自动化测试覆盖。动态学习技能只读可见，其他 Goal 的经验不可预览。

## 真实联网

Context7 首次匿名协议探测在 8 秒总截止下超时。适配器改为每次操作最多 12 秒（无自动重试）后，独立探测成功；后续实际 `resolve-library-id` 调用成功返回 1,778 字符，复用协商后仅发起一次工具请求，约 3 秒。该次完整探测与工具调用耗时约 7.33 秒。浏览器随后独立检测也通过。

这些是少量实时连通性观察，不是服务可用率或模型选择工具的准确率。GitHub 缺少 PAT，未执行真实 GitHub 联网调用；Playwright 没有运行后端，不宣称测试通过。没有为此调用 GLM，模型调用数为零。
