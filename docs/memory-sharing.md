# 会话记忆互联

输入框旁的“记忆互联”控制当前对话是否参与本Workspace的共享记忆检索。新对话默认关闭，选择会话、刷新或重启服务后按该会话保存的设置恢复。设置保存期间锁定发送和切换；运行中必须先结束或停止，才能更改。

## 使用

1. 在来源对话开启“记忆互联”。
2. 在需要参考该来源的另一个对话也开启。
3. 正常提问；Agent在当前请求前本地检索相关记忆，而非把所有对话拼到一起。
4. 任一侧关闭后，后续自动检索不再读取该来源／不再向该接收者提供共享条目。

这是双侧选择加入：来源同意分享、接收者同意参考。它不改变原有Goal、Task和Session的私有记忆作用域。Task执行器沿用其Goal对话的设置；不同Workspace没有共享池。新对话创建首个Goal时会话ID保留，因此用户先选的设置也保留。

## 共享哪些内容

允许的候选来自其他已开启Goal的背景笔记、已生效的Goal／对话学习记忆，以及该对话已激活且来源仍有效的结构化记忆。候选和失效／撤回记忆不共享，技能不通过此通道自动传播。

不自动检索原始聊天转录、整个附件或文件内容，也不传递其他Goal的任务约束、验收和运行状态。来源记忆可以是从文件中提炼的条目，仍要检查文件权限、新鲜度和隐私来源等级。

每条保留来源Goal、来源会话、版本、来源类型和适用条件。背景笔记明确标记为未验证；全部共享内容仅作历史参考，不能成为权限、验收证据或覆盖当前目标的指令。来源有冲突时仍保留其出处，不以“最新检索到”自动裁决哪个事实正确。

开启不代表一定有可用记忆：会话可能尚未形成笔记／生效条目，条目可能不相关、超额或被隐私／新鲜度检查排除。模型也可能没有及时提炼事实；本功能不承诺完整记住所有原始对话。

## 检索与上下文

`SharedMemoryStore`仅保存会话选择和revision，不另建原文副本池。检索前检查双侧设置、所属工作区、源状态、路径授权和来源等级，然后复用现有本地BM25排名，最多返回3条；明确禁止该通道调用外部Embedding。

单条正文与条件的序列化结构超过2,400字符则整体省略；回传条目合计不超过3,600字符，不能为了配额截断适用条件。原生模型请求将其放在可清理的advisory memory帧，保留来源；原有必保契约和工具权限不变。旧文本兼容通道追加同样有界、明确标注的参考数据，不宣称已经具备原生通道相同的wire预算保护。

每次模型调度前重新检查共享设置和已呈现条目的版本／有效性。若宿主外部程序在运行中更改设置、撤回记忆或使来源失效，下一次调度前停止，要求重启运行，不继续发送已知被撤回的共享帧。网页本身禁止运行中切换设置。

## 隐私与撤销边界

- 默认关闭；同Workspace内也不自动加入。
- 标记敏感／核心的Goal、会话、记忆或源文件不进入共享候选；敏感／凭据形状检测和原有安全文本检查同时生效，先过滤再排名。
- 检索采用共享条目时向原隐私保护层继承来源，不因改成“记忆”而降低数据等级；正常模型外发继续按原目的地策略检查。
- POST设置沿用Host/Origin/CSRF检查，校验Goal与会话绑定并用revision防止旧设置覆盖；模型工具不能开启共享。
- 共享开关控制这一条自动检索通道，不是Workspace文件访问权限开关；原有显式文件读取和宿主批准的工作区级知识仍按原规则处理。

**关闭不会自动删除已经产生的回复、任务产出、用户复制内容或其派生记忆，也不能撤回已经发给模型的信息。** 它停止后续从共享池检索，不等于让既有会话语义上“失忆”。界面按钮说明中也明确这一点。

现有文本检测是有限的规则与来源标签机制，不是能识别所有商业秘密或个人信息的语义分类器。对未标记、未命中规则的敏感内容不能承诺零泄漏；不应因为开启了开关就把它当成成熟的DLP保证。

## 验证

专项覆盖默认关闭、双侧开启、不同工作区、原始转录不检索、敏感／核心来源、文件来源继承、新鲜度、生效／撤回、输出配额、零外部Embedding、模型请求中的参考帧、CSRF与会话绑定。

Tabbit真实点击和输入验证开启、关闭、切换、新对话及刷新；模型响应为公开脚本夹具，验证的是网页到检索到上下文的接线，不是大模型记忆效果。浏览器发现并修复了“新对话”创建期间继续切换Goal的竞态，重新验收同时检查精确标题和开关归属。

见[本轮结果与证据](memory-sharing-validation-2026-11-12.md)。

后续真实GLM批量长流程另外检查“共享条目已检索并送达”和“模型正确使用条目”。二者分开判定，模型可能忽略已呈现背景、混淆来源与当前Goal标识，或沿用错误答案；不能以检索事件出现就宣布用户问题回答正确。当前工作区说明明确允许使用已授权背景，同时继续禁止借此修改来源Goal、继承来源约束或自证验收。详见[全部批次与失败](long-workflows-validation-2026-11-12.md)。
