# 分层上下文与跨对话检索：真实 GLM 验收（2026-11-12）

两项功能均已通过智谱普通 API `glm-5.3-flash` 实际执行。正式批次 live-v2 的 7 个冻结场景全部启动并完成，共 10 次模型请求；冻结的严格验收 **4/7通过**。这不是代码修复 Benchmark，也不能当作通用 Agent 能力分数。分层交接、压缩与共享检索接线有实际模型证据，回答格式和历史信息利用仍存在问题。

## 逐项结果与失败归因

| 冻结场景 | 严格结果 | 独立观察 |
|---|---|---|
| 默认关闭共享 | 通过 | 无共享帧，未向新对话提供来源代号，模型回答 unknown |
| 双方开启共享 | 通过 | 实际检索并注入有来源和适用条件的背景，模型正确回答 CORAL-R82 |
| 父子任务交接 | 未通过 | 实际调用 run_task，独立子 Session 读取 public.txt，有界结果带完整证据引用；人工验收仍为 review，没有修改文件。回答附加说明且 dependency_status 扩展了任务 ID/标题，没有严格返回冻结 JSON 值 |
| 压缩后关键事实 | 未通过；错误码金标存在缺陷 | 真实压缩 8 组历史，必保帧哈希保持，模型读出了验收、祖先约束、8 个完整读取和未运行验证。实际工具返回 invalid_arguments，冻结金标却写成 tool_failed；模型忠实报告实际错误码。另有额外说明文本，违反仅 JSON 要求 |
| 关闭共享后的原对话 | 未通过 | 后续共享检索已停止；之前的 CORAL-R82 答案确实仍在本次模型请求历史里，模型却输出 unknown，是历史答案利用失败 |
| 来源撤销后的新对话 | 通过 | 来源关闭，未检索/发送该背景，模型回答 unknown |
| 核心级来源的新对话 | 通过 | 合成背景标记 core 后过滤，未检索/发送来源代号，模型回答 unknown |

原始 `verification.json`、`cases.csv`、金标及所有失败记录不修改。事后从代码块提取字段只用于定位，不给失败补分：交接内嵌 JSON 六字段中五项严格相同，依赖状态语义一致但字符串不同；压缩案例的错误码金标与实物回执冲突，不能据此计算记忆准确率。该项应在下一版协议中先校验夹具与金标一致性，再开展新的冻结实验，本轮不重跑刷分。

共享检索五种状态的宿主与请求帧检查均符合设置；包含历史回答利用要求时，模型回答为 4/5通过。不能把“成功停止新检索”解释为“删除先前记忆”，也不能将它描述成检索召回率提升。来源为公开合成 Goal 背景，本轮未测真实私人材料、向量召回、跨 Workspace 检索或所有记忆类型。

## 实验配置与边界

- 接口：`https://open.bigmodel.cn/api/paas/v4`，Chat Completions 原生 Tool Calling，返回模型均为 `glm-5.3-flash`。只有别名，服务商未提供可冻结的权重修订；不声称锁定实际权重版本。
- temperature=1、top_p=0.95；Thinking enabled、clear_thinking=false、reasoning_effort=low；每请求输出上限1536。10个响应中2个报告 reasoning 文本存在，共275个 reasoning Token；不将未返回 reasoning 的响应解释成完整思维链。
- 并发1、传输尝试1、单请求超时120秒、单轮截止300秒、最多7个工具步骤/轮、整个批次最多16个请求。所有审批均拒绝；只读夹具，人工验收不由模型自证，不放宽 AppContainer 配置或权限。
- 普通会话 Token 窗口1,048,576、输入估算上限1,032,192、物理上限32MiB；固定官方本地 tokenizer 修订及 SHA256 在请求审计内。压缩场景另固定22,000 JSON字节输入压力预算、48,000字节硬上限；**字节不是 Token**。
- 压缩场景从30,191压至20,826序列化JSON字节，保护3个必保帧、清理8组历史，未达到70%目标但低于硬输入预算；没有删除必保信息以追求更小体积。
- 压缩前的9次工具执行（1次拒绝、8次读取）由宿主夹具真实生成，不是模型自主长任务。交接中的 run_task、read_file 则是模型实际决策。两者分开计数。
- 所有7场景都是已知合成诊断；其中共享开关沿用同一接收对话，不能当作7个独立任务、重复稳定性或未见任务泛化实验。
- 记录的是隐私检查前准备请求、上下文审计、真实服务响应元数据和工具回执；不抓取鉴权头，不启用受保护传输的原始 wire 日志，reasoning 正文省略并保留哈希。
