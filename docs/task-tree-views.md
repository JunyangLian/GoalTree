# 阶段卡片与完整任务树

右侧以阶段卡片展示目标进展。顶部统计有效验收的叶子任务，不把父阶段和子任务重复加总；归档和取消任务不计入分母。阶段自身的验收规则保持原样，子项全部完成不代表父阶段已经获准完成。

- 已完成阶段默认收起；正在推进、待验收、阻塞及第一个待推进阶段默认展开，允许多个并行阶段同时展开。
- 点击阶段标题展开/收起，点击子任务就地查看说明、验收条件、进展、产出记录索引及最近变更。历史规格的产出会单独标记；完整产出正文仍在原对话/证据中，不在浏览器中自动加载全部历史。
- 手动展开状态按工作区与Goal隔离，在本次页面会话内保留；普通轮询不会将其重置，刷新页面后重新采用默认展开规则。
- 节点实际新增/改变后短暂标亮，首次加载及无变化轮询不伪造更新；尊重系统减少动画设置。

右上角↗打开完整任务树，目标、阶段和子任务按父子关系排列。支持放大、缩小、适应画布、滚动与拖动空白画布；点击节点显示详情。层级为实线，依赖默认隐藏，勾选后用带箭头的虚线表示。布局不以依赖排序，避免将“前置条件”误当成父子关系。

视图使用本地JavaScript、CSS和SVG，不新增前端框架、CDN、模型请求或联网权限。所有节点仍由Agent通过原对话/工具更新，卡片和图上没有拖拽改节点、删除任务或绕过审批入口。

对500节点做了离线布局完整性检查，不代表该规模的浏览器性能评测；大树仍需缩放/滚动，当前没有图形虚拟化或自动依赖避障。最近变更来自工作区最近40条审计事件中的所选任务记录，每个节点最多显示4条，不能当作全部历史。验收证据见[阶段卡片报告](releases/goaltree-2026-11-10.md)。
